AppFill

Job applications ask for the same details in a slightly different form each time. I designed and built a Chrome extension that fills them from one right-click and outlines whatever it can't answer.

reportThe problem

Same answers, every application

Most of my time on each application went to retyping answers I had already given. Greenhouse, Lever, Ashby and Workday all want name, email, phone and LinkedIn, then ask what Chrome's autofill never touches: work authorization, sponsorship, years of experience, why this company. Picking portfolio pieces and writing to the hiring team got whatever time was left.

ads_clickThe core pattern

Start from the right-click

Autofill lives in the menu already under your hand: no toolbar popup, no per-site setup, and it works inside embedded application frames.

  • check_circleFill blanks, never overwrite. Only empty fields are touched, so running it twice is harmless.
  • check_circleShow the gaps. Fields it can't place get a dashed amber outline, not a best guess.
  • check_circleDon't agree on my behalf. No checkbox is ticked from a guess; password and file fields are skipped.

manage_searchHow it reads a field

Every input leaves clues

A field might have a label, only a placeholder, or just a name like job_application[first_name], so AppFill flattens every clue into plain words and checks 31 patterns. Each empty field tries four sources in order: answers saved for this site, the autocomplete hint, my custom answers, then the patterns. Dropdowns also match short values, so OR finds Oregon.

bookmark_addedFilling the gaps

Answer a gap once, or point at the field

Platform questions like work arrangement or pronouns get two fixes instead of a guess.

  • check_circleRemember this site. I answer once by hand, then Remember my answers on this site fills the next form.
  • check_circleSaved per host. Answers from one Greenhouse posting fill the next Greenhouse posting too.
  • check_circleFill this field with… Right-clicking a field lists every saved value with a preview, skipping empty ones.
  • check_circlePointing overwrites. Choosing one field is a clear instruction, so it replaces what's there.

tuneSettings

A form for filling forms

Settings hold personal details, address, links, work, education and four yes-or-no questions, plus custom answers, remembered sites, and export and import. It saves as you type. Custom answers match on a few key words, so "why do you want, why this company" catches most versions of that question.

lockPrivacy

Everything stays on this computer

An autofill tool holds the details you'd least want leaking. The profile, custom answers and remembered sites live in local extension storage. Nothing is synced, sent or logged; export and import handle moving to a new machine.

scienceProcess and testing

Built with Claude, tested in a real browser

I set the behavior, Claude wrote the code in one session, then ran it in Chromium against a Greenhouse-style test form.

  • check_circle13 of 14 fields filled on the first pass, with no saved answers.
  • check_circle15 of 15 filled after remembering the site once, including the dropdown and checkbox.
  • check_circle0 password, file or unsaved checkbox fields touched.
  • check_circle1 bug caught in test screenshots, before any real application.

Things to improve

  • radio_button_uncheckedCustom dropdowns. Workday and type-to-search pickers get outlined, not filled; an adapter that opens each picker and picks the match would close the biggest gap.
  • radio_button_uncheckedResume uploads. Extensions can't attach files, but the notice could flag an empty upload field.
  • radio_button_uncheckedKeyboard shortcut. One key to fill the page would suit applications I finish without the mouse.
  • radio_button_uncheckedMore than one profile. Switching profiles from the menu would cover full-time and freelance applications, which want different titles, links and rates.
