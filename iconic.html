Iconic

General design tools don't know Material's rules, so I designed and built Iconic, a vector editor made only for Google Material icons. It runs in the browser on PC and phone and exports the single-path format Google ships.

reportThe problem

Material icons have rules general tools don't know

A Material icon is a 24dp square with 2dp padding, drawn to keylines in Outlined, Rounded or Sharp, and shipped as one filled path on a 960-unit grid. Illustrator and Figma can draw that but don't know it, so I fixed exports by hand: strokes, overlaps and white fake holes shifted or filled in elsewhere. I wanted to draw once and get Google's format out, on PC or phone.

routeProcess

Live in an hour, shaped over 28 commits

I built Iconic with Claude in one day: I made the product calls, Claude wrote and tested the code, and each feature shipped to the live app as its own commit.

  • check_circleShip first. A basic editor was live on GitHub Pages in hour one; I reviewed every build by using it.
  • check_circleFigma panels, Illustrator keys. V, A, P, Ctrl+D and Alt-drag work as expected, so nothing new to learn.
  • check_circleFast over pure. TypeScript plus Google's Skia in WebAssembly instead of Rust, with that option kept open.
  • check_circleQuestions before features. Asking first produced the export plan, Roboto Flex as the UI font and a GPL v3 license.

categoryMaterial mode

The specs are built in

Material rules are defaults in Iconic, not things to remember.

  • check_circle24dp artboards, whole-pixel snapping and a keyline template with padding, live area and base shapes.
  • check_circleOne choice of Outlined, Rounded or Sharp sets line ends, corners and corner radius.
  • check_circlesnake_case names, exported as arrow_back_24dp.svg the way Material Symbols names them.
  • check_circleA Material mode switch hides it all for other icon work: sizes 16 to 64, no dp suffix.

joinBooleans and badges

Combined shapes stay editable

Combining shapes never destroys them, so one base icon can carry a whole family of badges.

  • check_circleLive booleans. Union, Subtract, Intersect and Exclude stay editable, computed by Skia PathOps, Chrome and Android's path engine.
  • check_circleComponents. Any artboard or selection becomes a component; linked copies follow every edit.
  • check_circleKnockout badges. Plus, minus, check, close, alert and arrows cut a shape-matched gap, exact in export.
  • check_circleMake variants. Pick bases and badges to generate every combination, named like file_add.

ios_shareExport

What you draw is what Google gets

Export outlines strokes, merges every shape and clips to the artboard, giving one filled path on the 960-unit grid while the working file stays editable.

  • check_circlePixel check. The working icon and merged path are rendered and compared pixel by pixel before export.
  • check_circleWarnings. Flags extra colors and off-artboard art, and turns white fake holes into a real Subtract.
  • check_circleMerged preview (Ctrl+Y) shows every icon as it will export while you keep editing.
  • check_circleFormats: SVG, Android Vector Drawable, PNG at every Android density, and an OTF/WOFF icon font.

font_downloadBorrowed from type design

Font tools, pointed at icons

Type designers solved smooth curves and consistent weights long ago, so I picked eight FontLab 8 features and built them for icons.

  • check_circleTunni lines. Drag the dashed line between a curve's handles to make it fuller or flatter.
  • check_circlePower Nudge and Smart Corners. Points move without flattening curves; rounded corners stay one point.
  • check_circleAudit. Flags flat curves, missing extremes, tiny segments and off-grid points, each with a Fix button.
  • check_circleWeight masters. Draw a base and bold master, matched point for point, and generate weights 100 to 700.

smartphonePC and phone

One app, installed anywhere

Iconic is a Progressive Web App: install it from Chrome or Edge, or add it to an iPhone or Android home screen. It works offline and saves as you go. On a phone the panels fold behind toolbar buttons, and pinch zoom, touch and stylus all work. There's no server or account, and the font library loads only when you export a font.

scienceTesting

Every feature checked in a real browser

Each feature was tested with scripted mouse and keyboard input and measured results, and the tests caught real bugs.

  • check_circleSmart Corners: a pen-drawn square rounded to R 2 matched a 2px rounded rectangle exactly.
  • check_circleAudit: a deliberately messy path got 10 flags, and Fix all cleared every one.
  • check_circleIcon font: typing file_add drew the plain file, so longer names now match first.
  • check_circlePixel check: it caught badges exporting in the wrong color; they now take the icon's color.

Things to improve

  • radio_button_uncheckedSVG import. Iconic exports cleanly to Figma and Illustrator but can't open their files yet, so import with round-trip tests would let me bring existing sets in.
  • radio_button_uncheckedFill and optical-size axes. Weight is the only axis today, and the masters system could also cover Material Symbols' fill and optical size.
  • radio_button_uncheckedCleaner generated weights. In-between weights land on fractional coordinates that Audit flags, so snapping during Generate would save a Fix all step.
  • radio_button_uncheckedMore export targets. The font has no WOFF2 and there's no iOS asset export yet, and both would round out the developer handoff.
  • radio_button_uncheckedReal-device testing. Testing used scripted input in a desktop browser, so a pass on an iPhone and an Android tablet with a stylus would show where touch needs work.
