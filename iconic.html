Iconic

General design tools don't know Material's rules, so I designed and built Iconic, a vector editor made only for Google Material icons. It runs in the browser and exports the single-path format Google ships.

Material icons have rules general tools don't know

A Material icon is a 24dp square with 2dp padding, drawn to keylines in Outlined, Rounded or Sharp, and shipped as one filled path on a 960-unit grid. Illustrator and Figma can draw that but don't know it, so I fixed exports by hand. I wanted to draw once and get Google's format out.

So I built Iconic with Claude in one day. I made the product calls, Claude wrote and tested the code, and a basic editor was live in the first hour. Figma-style panels and Illustrator shortcuts mean there's nothing new to learn.

The specs are built in, all the way to export

Material rules are defaults, not things to remember: 24dp artboards with pixel snapping and keylines, one Outlined, Rounded or Sharp choice that sets corners and line ends, and Material Symbols naming. A Material mode switch turns it all off for other icon work.

Export outlines strokes, merges every shape and clips to the artboard, giving Google's single filled path while the working file stays editable. A pixel check compares the two before export, and every feature was tested in a real browser, which caught bugs like badges exporting in the wrong color.

Combined shapes stay editable

Combining shapes never destroys them. Live booleans stay editable, components update every linked copy, and knockout badges cut a shape-matched gap, so one base icon can carry a whole family of variants, generated and named for you.

Font tools, pointed at icons

Type designers solved smooth curves and consistent weights long ago, so I brought FontLab's ideas to icons: Tunni lines for balanced curves, Power Nudge and Smart Corners that keep curves and corners intact, an Audit that flags and fixes bad points, and weight masters that generate 100 to 700.

What changed since launch

After the first-hour version came the Figma-style interface, Material specs, live booleans with Google-format export, badges and variants, and the type-design tools. Smaller fixes kept Subtract holes from filling in on export and gave badges the icon's color.

Things to improve

Next up: SVG import with round-trip tests so I can bring existing sets in, fill and optical-size axes alongside weight, generated weights that snap to the grid, and WOFF2 and iOS exports to round out the developer handoff.
